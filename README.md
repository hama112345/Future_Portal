# 診断ツール ポータル

担当コンサルタントが、その場で使いたい診断を選んで始めるための入口ページです。

| | | |
|---|---|---|
| ポータル | `index.html` | v1.2.0 |
| 危機管理アセスメント | `ra/` | v3.0.0 |
| キャッシュフロー診断 | `cf/` | v2.0.0 |
| 資産形成＆ライフプラン診断 | `lp/` | v1.0.0 |

## はじめに読むもの

**`deploy/導入手順.md`** に、GitHub Pagesでの公開から現場での使い方まで一通り書いてあります。

## いまの状態

- **回答は外部に送っていません。** 3つとも判定はページの中で行うので、GASもスプレッドシートも使いません
- オフラインでも最後まで動きます
- 記録は**PDFのみ**。結果画面の保存ボタンから、結果・回答の控え・同意日時を1つのPDFにできます
- 3つとも、診断を始める前に**回答の取り扱いへの同意のチェック**が必要です
- 担当者名はポータルで入れると、どの診断にも引き継がれてPDFに印字されます

## 承知しておくこと

- 判定の中身（配点・ランクの閾値・診断タイプの文言）は**ページのソースから読めます**。
  外部へ送らないことを優先したための割り切りです
- GitHub Pagesは**誰でも開けるURL**です。お客様の氏名・連絡先は入力しないでください
- **PDFはお客様の個人情報です。** 保管場所・保存期間・破棄の手順を決めてから配ってください

## フォルダについて

アップするのは `index.html` ／ `ra/` ／ `cf/` ／ `lp/` の4つで足ります。
`gas/` は以前のサーバー側コードの控え、`deploy/` は手順書です。どちらも動作には使いません。
