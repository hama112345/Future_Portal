# 診断ツール ポータル

担当コンサルタントが、その場で使いたい診断を選んで始めるための入口ページです。

| | |
|---|---|
| ポータル | `index.html` |
| 危機管理アセスメント | `ra/` （v2.0.2） |
| キャッシュフロー診断 | `cf/` （v1.6.5） |

## はじめに読むもの

**`deploy/導入手順.md`** に、GASの設置からGitHub Pagesでの公開、現場での使い方まで一通り書いてあります。

## いまの状態

- 回答の**スプレッドシートへの記録は止めています**（GASの `CONFIG.RECORD = false`）
- 記録は**PDFのみ**。結果画面の保存ボタンから、結果と回答の控えを1つのPDFにできます
- 診断を始める前に、**回答の取り扱いへの同意のチェック**が必要です。同意した日時はPDFに印字されます
- GitHub Pagesは**誰でも開けるURL**です。お客様の氏名・連絡先は入力しないでください

## 公開前に必ず直すところ

1. `ra/index.html` の `CONFIG.endpoint` に、GASのウェブアプリURLを入れる
2. `TOKEN` を `test` から30文字以上のランダムな文字列へ変更（HTML側・GAS側の両方）
3. 自社サーバーへ移したら、アクセス制限（Basic認証）をかける
